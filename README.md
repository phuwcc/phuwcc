<h3>Research & Projects</h3>

- **Thermal Image Understanding** — Deep learning approaches for photovoltaic/infrared imagery and anomaly detection.
- **Physical & Manipulation AI** — Exploring perception, reasoning and interaction for robotic manipulation.
- **Robot Simulation** — Building realistic environments and importing 3D assets into robotics simulators.
- **Quadruped Robotics** — Kinematics, trajectory planning, control and simulation of four-legged robots.
- **Computer Vision** — Object detection and image-processing pipelines using modern deep-learning frameworks.
